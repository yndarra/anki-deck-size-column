## Deck Size Column

Settings open in a window (Tools → Add-ons → Config): the column header and color points (badge color by size for light and dark theme), smooth gradient or steps.

Настройки открываются в окне (Инструменты → Дополнения → Config): заголовок столбца и цветовые точки (цвет плашки по размеру для светлой и тёмной темы), плавный градиент или ступеньки.
