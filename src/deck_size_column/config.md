## Deck Size Column

Settings open in a window (Tools → Add-ons → Config): the column header and color levels (badge color by size for light and dark theme, like Note Size).

Настройки открываются в окне (Инструменты → Дополнения → Config): заголовок столбца и цветовые уровни (цвет плашки по размеру для светлой и тёмной темы, как в Note Size).
