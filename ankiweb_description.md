<b>Deck list on the main screen: a deck size column, custom (short) column headers and wrapped long deck names.</b>

<ul>
<li><b>Size column</b>: note text + media files of each deck, including subdecks (like the New/Learn/Due counts). Hover a cell to see text, media, number of files and notes separately. A media file used by several notes is counted once. Sizes are calculated in the background (≈0.5 s for 50k notes) and cached.</li>
<li><b>Custom column headers</b>: e.g. "Learn." / "Due" instead of the long default ones. Leave empty to keep Anki's text.</li>
<li><b>Wrapped deck names</b>: a long name wraps onto new lines inside a fixed-width column, like on mobile but without "…". It no longer stretches the whole table, and wrapped lines start under the name, not under the indent.</li>
</ul>

Settings: <b>Tools → Deck list settings…</b> (or the Config button). Changes apply immediately. Each feature can be turned off.

The add-on does not replace Anki's deck list HTML. It edits the finished table with a small script, so it works alongside other add-ons.
